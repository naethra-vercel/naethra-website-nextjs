# Naethra Technologies

Marketing site for Naethra Technologies — **Next.js 15 App Router**, React 19, TypeScript, Tailwind CSS 4, WordPress REST API.

## Scripts

```bash
npm run dev      # next dev
npm run build    # next build
npm run start    # next start (Node.js production server)
npm run lint     # eslint
npm run format   # prettier
```

## Environment

See [`.env.example`](.env.example). Public WordPress/reCAPTCHA values use `NEXT_PUBLIC_*`.

## Deploy

Node.js hosting on cPanel or a VPS — see [`DEPLOYMENT.md`](DEPLOYMENT.md). This project is **not** configured for Cloudflare Workers or static export.
